<h1 align="center">Planning UM</h1>

<p align="center">
  Application Android pour consulter son emploi du temps ADE de l'Université de Montpellier.
</p>

---

## Fonctionnalités

- Vue journée avec grille horaire, une couleur par matière
- Navigation par semaine ou par mois, jours avec cours mis en évidence
- Détails d'un cours : salle, enseignant, groupes
- Planning mis à jour à chaque ouverture, consultable hors connexion
- Plusieurs profils pour suivre le planning d'autres personnes

## Installation

1. Télécharger le fichier `.apk` depuis la page [Releases](../../releases).
2. L'ouvrir sur le téléphone et autoriser l'installation d'applications inconnues.
3. Au premier lancement, coller son lien iCal (voir ci-dessous).

## Utilisation

Pour récupérer le lien de son emploi du temps :

1. Se connecter à l'ENT et ouvrir **Planning** depuis l'accueil.
2. Cliquer sur **iCal**.
3. Copier le lien proposé et le coller dans l'application.

Pour suivre un autre planning, toucher son nom de profil en haut à droite puis **Ajouter un profil**, avec le lien iCal de ce second planning.

## Développement

Projet Kotlin / Jetpack Compose, à ouvrir avec Android Studio.
